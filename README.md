# Подход

Приложение для тренировок в зале и дома: каталог упражнений с техникой, план и запись тренировок, прогресс, блокнот и калькуляторы. Работает в браузере, ставится на телефон как приложение и открывается без интернета.

Живая версия: https://meanuga.github.io/podhod/

## Что умеет

- Анкета при первом запуске: опыт, где занимаешься, инвентарь дома, рост, вес, цель. По ней подбираются упражнения и программа.
- Каталог из 67 упражнений: грудь, спина, ноги, плечи, руки, пресс и кардио. Внутри группы есть подгруппы (например, у рук — бицепс, трицепс, предплечья).
- Экран «Как выполнять» с шагами, частыми ошибками и советом.
- План тренировки, запись подходов, таймер отдыха, подсказка веса на основе прошлой тренировки.
- Прогресс: история, рекорды, графики, вес тела.
- Блокнот, калькулятор одноповторного максимума и калькулятор блинов.
- Готовые и свои программы, напоминания о тренировках в календарь телефона.
- Копия данных в файл и восстановление из него.

Все данные хранятся только в браузере на устройстве (localStorage). Никуда не отправляются.

## Как устроен проект

```
index.html          страница
css/style.css       оформление
js/data.js          данные: упражнения, подгруппы, программы, варианты анкеты
js/app.js           вся логика и экраны
js/sw-register.js   подключение сервис-воркера
sw.js               офлайн-кэш
manifest.webmanifest  описание приложения для установки
icon-*.png, apple-touch-icon.png  значки
```

Сборки нет: это обычные файлы без зависимостей. Чтобы запустить у себя:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000. Сервис-воркер работает только по http(s), а не при открытии файла двойным щелчком.

## Как добавить упражнение

Откройте `js/data.js` и добавьте запись в массив `EX` по образцу соседних:

- `id` — короткое латинское имя, `n` — название, `g` — группа (`chest`, `back`, `legs`, `shoulders`, `arms`, `core`, `cardio`);
- `m` — `'w'` для упражнений с весом или `'r'` для повторений, `u: 'сек'` или `u: 'мин'` для упражнений на время;
- `need` — какой инвентарь нужен дома (`[[]]` значит ничего), без него упражнение считается залом;
- `s` — шаги, `e` — частые ошибки, `t` — совет.

Подгруппы по `id` задаются в объекте `SUBMAP` ниже.

## Обновление на GitHub Pages

Загрузите изменённые файлы в репозиторий. После изменения файлов увеличьте `VERSION` в `sw.js`, иначе телефон какое-то время будет показывать старую версию из кэша.
